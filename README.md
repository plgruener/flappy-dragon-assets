# Flappy Dragon Assets

This repository contains a partial asset dump of the game Flappy Dragon by Coré Ventura.

## Repostory Structue
**dump**: Unorganized files extracted directly from the game. Files may have names that do not reflect their current purpose.
**organized**: Files that have been organized/renamed according to purpose. Also contains consolidated data files built from dumped game data for the purpose of convenient browsing. This is a constant work in progress and may contain outdated files.
